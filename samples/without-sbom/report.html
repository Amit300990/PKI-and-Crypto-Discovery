What this scan cannot see

  • Keys held inside an HSM or cloud KMS. Only PKCS#11 config and module references are found; pull the keys from the HSM/KMS admin API.
  • Keystores with a non-default password are listed but not opened.
  • Keys generated at runtime and never written to disk.
  • Algorithms used inside compiled or obfuscated JARs. Use the CBOM from --with-sbom.
  • Secrets in external vaults (HashiCorp Vault, AWS Secrets Manager, ...) that config only references by name.
